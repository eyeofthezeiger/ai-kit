# Claude Code

- Skills: Claude Code reads skills from `.claude/skills/<name>/SKILL.md` in a project, or `~/.claude/skills/` for your user.
- To use one from this kit, copy or symlink `skills/<name>/` into that folder.
- MCP servers: add them with `claude mcp add`, or in the project's `.mcp.json`.

Check the current Claude Code docs before relying on these paths.
